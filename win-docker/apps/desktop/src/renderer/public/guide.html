WinDock setup guide

Created and owned by Saurabh Gupta

Offline instructions for Docker, Compose, private registries, and Kubernetes on WSL2—without Docker Desktop.

Start here

  1. Install and open WinDock.
  2. On its first launch, it checks WSL2, Docker CLI, kubectl, and Buildx and repairs missing prerequisites with Windows permission when required.
  3. Wait for the dashboard badge to show Engine ready.

Which command should I use? Use docker for normal development: containers, images, Compose, Buildx, and existing CI scripts. Use wincolima only to manage the WinDock runtime itself: start/stop, resources, diagnostics, and embedded Kubernetes.

docker context use wincolima
docker version
docker run --rm hello-world

Containers and images

Use Run container for common runs, or use your existing terminal workflow.

docker run -d --name web -p 8080:80 nginx
docker logs web
docker pull nginx:alpine

Published ports are available from Windows at http://localhost:PORT.

Compose projects

Choose a Compose file in the Compose tab. WinDock remembers recent projects and can restart the project selected for auto-start.

docker compose up -d
docker compose ps
docker compose down

Private registries

Use the Registry tab for Docker Hub, Harbor, Nexus, or another OCI registry. Docker stores the credential in its credential manager. WinDock keeps only the registry and username so you do not need to re-enter a token for normal pulls and builds.

docker pull registry.example.com/team/app:tag
docker buildx build --load -t sample:local .

Kubernetes

Enable embedded Kubernetes from the Kubernetes tab. WinDock runs k3s in its managed WSL distribution.

wincolima kubernetes status
wincolima kubernetes kubectl get nodes
wincolima kubernetes kubectl get pods -A

Recovery and diagnostics

  • For a source checkout, double-click launch-wincolima.bat.
  • For a packaged installation, close and reopen WinDock; its embedded bootstrapper repairs the runtime when possible.
  • Run wincolima status to check Docker and Kubernetes.
  • Read %LOCALAPPDATA%\WinColima\desktop.log if recovery needs attention.

Safety: wincolima delete --purge removes containers, images, and volumes from the managed distribution. Use it only when that data can be discarded.
